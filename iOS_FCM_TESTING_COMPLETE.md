## iOS App Installation Instructions

### Step 1: Rebuild iOS App with Updated Code

Run the following commands on your Mac:

```bash

# Clean build folder
rm -rf build/
rm -rf derived*/

# Replace with your actual UDID from Xcode
xcodebuild -scheme TheNileKartApp \
  -configuration Release \
  -derivedDataPath build \
  -destination 'platform=iOS,id=YOUR_DEVICE_UDID'

# Install to physical device
xcodebuild -scheme TheNileKartApp \
  -configuration Release \
  -derivedDataPath build \
  -destination 'platform=iOS,id=YOUR_DEVICE_UDID' \
  install
```

### Step 2: Get Your Device UDID

To find your device UDID:

1. Connect your physical iOS device to your Mac via USB
2. Open Xcode → Window → Devices and Simulators
3. Select your device
4. Copy the Identifier (UDID)

Example UDID format: `00008150-0016554E3412401C`

## Troubleshooting Guide

### ❌ Issue: No notification permission prompt on app launch

**Solution:**
```bash
# Reset notification settings on device
Settings → TheNileKart → Notifications → Toggle OFF, then ON
```

### ❌ Issue: "FCM Token is nil"

**Solution:**
1. Ensure Firebase SDK is properly initialized
2. Check pod installation: `pod install`
3. Rebuild app: `xcodebuild clean -scheme TheNileKartApp`
4. Force app kill and relaunch

### ❌ Issue: "No JWT token, storing for later..." in console

**Solution:**
1. Log in to the app first
2. App should resend pending token after login
3. Check console for: `🔄 Resending token after login...`

### ❌ Issue: Backend returns 401 Unauthorized

**Solution:**
1. Ensure JWT token is valid: `curl -X GET "http://40.172.190.250:5000/api/auth/me" -H "Authorization: Bearer YOUR_JWT_TOKEN"`
2. Check token expiration
3. Log in again to get fresh token

### ❌ Issue: Backend returns 404 for push notification endpoint

**Solution:**
1. Verify backend is running: `ssh ubuntu@40.172.190.250 "pm2 status"`
2. Check API response: `curl http://40.172.190.250:5000/api/health`
3. Restart backend if needed: `ssh ubuntu@40.172.190.250 "pm2 restart thenilekart-backend"`

### ❌ Issue: "Firebase service account key not found"

**Solution:**
Backend needs Firebase credentials. Ensure `.env.production` on EC2 contains:
```bash
FIREBASE_SERVICE_ACCOUNT_KEY='{"type":"service_account",...}'
```

## Key API Endpoints Reference

### Register Device Token (POST)
```
POST /api/push-notifications/register-token
Authorization: Bearer {JWT}
Content-Type: application/json

{
  "deviceToken": "firebase_fcm_token_here"
}
```

### Check Token Status (GET)
```
GET /api/push-notifications/check-token
Authorization: Bearer {JWT}
```

### Send Notification (POST)
```
POST /api/push-notifications/send
Authorization: Bearer {JWT}
Content-Type: application/json

{
  "deviceToken": "target_device_token",
  "title": "Notification Title",
  "body": "Notification Message",
  "actionType": "orders|products|home",
  "actionData": {"orderId": "123"}
}
```
