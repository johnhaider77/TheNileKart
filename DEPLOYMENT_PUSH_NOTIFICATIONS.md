## Technical Details

### Why This Matters

Real FCM (Firebase Cloud Messaging) tokens:
- Are generated by Firebase SDK
- Are 150+ characters long
- Are unique per device/app installation
- Expire and need to be refreshed
- Are required by Firebase Admin SDK

Placeholder tokens like `exampleToken123`:
- Are only 15 characters
- Cannot be used to send real notifications
- Are rejected by Firebase infrastructure
- Will always cause notification delivery to fail

### Validation Logic

```javascript
function isValidFCMToken(token) {
  if (!token) return false;
  
  // Reject test tokens
  const testTokens = ['exampleToken123', 'test', 'demo', 'example'];
  if (testTokens.some(t => token.toLowerCase().includes(t.toLowerCase()))) {
    return false;
  }
  
  // Real FCM tokens are 150+ chars
  return token.length > 100;
}
```
