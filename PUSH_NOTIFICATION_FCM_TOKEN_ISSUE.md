# Push Notification FCM Token Issue - Fix Guide

**Date:** February 16, 2026  
**Issue:** Push notifications are not being sent - device tokens are invalid  
**Root Cause:** iOS app is registering a test token (`exampleToken123`) instead of real Firebase token

## Problem Analysis

### What Happened
1. User tried to send push notification via seller dashboard
2. Request was successful (HTTP 200), but notification was NOT sent
3. Backend response indicated: "All 1 device token(s) are invalid/short"
4. Registered token: `exampleToken123` (15 characters - clearly a test token)

### Why Backend Rejected It
Real Firebase FCM tokens have these characteristics:
- **Length:** 150+ characters (base64-like string)
- **Format:** Alphanumeric with special characters
- **Source:** Generated by Firebase Cloud Messaging SDK at runtime

Our backend validation rejects:
- Tokens shorter than 100 characters
- Known test tokens: 'exampleToken123', 'test', 'demo', 'example'
- Any obviously invalid tokens

```
Token Length: 15 characters

```

## Solution: Enable Real FCM Token Generation on iOS

### What Needs to Happen
The iOS app must:
1. Initialize Firebase Messaging properly
2. Retrieve the real FCM device token from Firebase
3. Register it with the backend at `/api/push-notifications/register-token`

### Step-by-Step Fix

#### Step 1: Verify Firebase Configuration
```swift
// In AppDelegate or Main.swift
import FirebaseCore
import FirebaseMessaging

@main
struct TheNileKartApp: App {
    init() {
        // Initialize Firebase
        FirebaseApp.configure()
        
        // Set up messaging delegate
        Messaging.messaging().delegate = self
        
        // Request notification permissions
        UNUserNotificationCenter.current().delegate = self
    }
}
```

**Verify Checklist:**
- ✅ GoogleService-Info.plist is in Xcode project
- ✅ File is added to all targets (check Build Phases → Copy Bundle Resources)
- ✅ Firebase is imported correctly
- ✅ FirebaseApp.configure() is called in app initialization

#### Step 2: Request Notification Permissions
```swift
// Request permission from user
UNUserNotificationCenter.current().requestAuthorization(options: [.alert, .sound, .badge]) { granted, error in
    if granted {
        print("✅ Notification permission granted")
        DispatchQueue.main.async {
            UIApplication.shared.registerForRemoteNotifications()
        }
    }
}
```

**Note:** User must tap "Allow" on the iOS permission dialog

#### Step 3: Retrieve Real FCM Token
```swift
Messaging.messaging().token { token, error in
    if let error = error {
        print("❌ Error getting FCM token: \(error)")
        return
    }
    
    guard let token = token else {
        print("❌ No FCM token available")
        return
    }
    
    print("✅ FCM Token retrieved successfully!")
    print("🔐 Token: \(token)")
    print("📏 Token length: \(token.count) characters")
    
    // Register this real token with backend
    sendTokenToBackend(token: token)
}
```

#### Step 4: Register Token with Backend
```swift
func sendTokenToBackend(token: String) {
    guard let userId = UserDefaults.standard.string(forKey: "userId") else {
        print("❌ No userId found")
        return
    }
    
    let urlString = "https://thenilekart.com/api/push-notifications/register-token"
    guard let url = URL(string: urlString) else { return }
    
    var request = URLRequest(url: url)
    request.httpMethod = "POST"
    request.setValue("application/json", forHTTPHeaderField: "Content-Type")
    request.setValue("Bearer \(YOUR_AUTH_TOKEN)", forHTTPHeaderField: "Authorization")
    
    let payload = ["deviceToken": token]
    request.httpBody = try? JSONSerialization.data(withJSONObject: payload)
    
    URLSession.shared.dataTask(with: request) { data, response, error in
        if let error = error {
            print("❌ Failed to send token to backend: \(error)")
            return
        }
        
        print("✅ Token registered with backend!")
    }.resume()
}
```

## Backend Validation Rules

The backend will REJECT tokens if:
- Length < 100 characters
- Contains 'exampleToken123', 'test', 'demo', 'example'
- Is null or empty

The backend will ACCEPT tokens if:
- Length > 100 characters
- Doesn't contain test indicators
- Looks like real Firebase format
